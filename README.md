# TelegramJoinRequestsBot

Telegram-бот для подачи и рассмотрения заявок на вступление в приватную беседу.

## Возможности

- Приём заявок с фотографией и игровым никнеймом.
- Отправка заявок в закрытый чат администрации.
- Принятие и отклонение заявок.
- Создание одноразовых ссылок-приглашений со сроком действия 24 часа.
- Переписка администрации с заявителями через бота.
- Управление доступом к заявкам командами /add и /del.
- Настройка шаблона заявки.
- Сохранение данных в data.json.

## Переменные окружения

- BOT_TOKEN — токен бота от BotFather.
- OWNER_ID — Telegram ID владельца бота.
- ADMIN_CHAT_ID — ID закрытого чата администрации.
- MAIN_CHAT_ID — ID приватной беседы для вступления.
- DATA_FILE — файл хранения данных (необязательно).

## Запуск

Установите зависимости:

    pip install -r requirements.txt

Запустите бота:

    python bot.py

## Размещение на Bothost

1. Загрузите файлы проекта в GitHub.
2. Подключите репозиторий к Bothost.
3. Выберите ветку main.
4. Добавьте переменные окружения.
5. Убедитесь, что настроено постоянное хранилище для data.json.
6. Запустите бота.

Бот должен быть администратором приватной беседы
с правом создания ссылок-приглашений.
